# 06 安裝

Windows 11＋NVIDIA 顯卡。執行環境與模型以 `C:\AI` 為慣例（不要放進雲端硬碟同步的資料夾）；要放別處就設下方的環境變數。**已經裝了 Comfy Desktop 時，ComfyUI 直接用它**（`configs\profile.cmd` 自動偵測，見 `AGENT_SETUP.md` §2a），`C:\AI` 底下只需要語音環境。

## 1. 資料夾慣例

工具不放這裡：各腳本直接用本 repo 的 `tools\`（見 `AGENT_SETUP.md` §2e）。

```
C:\AI\
  H3\            ComfyUI＋H3 主環境（venv＋ComfyUI 程式＋models；用 Comfy Desktop 時不需要）
  Voice\         語音環境（VoxCPM2、faster-whisper、stable-ts、audio-separator、edge-tts）
  BreezeTTS\     Breeze TTS 2（程式庫 breeze-tts、權重 breeze-tts-2、獨立 venv；只用來設計角色參考音）
  BreezyVoice\   BreezyVoice（code、model、winstub、Python 3.10 venv；所有台詞配音）
```

### 為什麼模型權重與 venv 不放進 repo

模型分成兩部分：**程式碼**（模型的結構，`pip install` 裝的就是它，很小）與**權重**（訓練出來的幾十億個數字，也就是模型「學到的東西」，`.safetensors`、`.ckpt`、`.gguf` 等檔，單檔動輒數 GB）。本 repo 只放腳本與下載清單，權重與 venv 留在每台電腦本機，理由：

| 理由 | 說明 |
|---|---|
| 太大 | 全部權重約 150GB；GitHub 單檔上限 100MB。repo 放在雲端硬碟時，也會被整包同步，吃空間又容易同步出錯（venv 有上萬個小檔更糟） |
| 授權 | 權重屬於各模型作者，各有條款（例如 Qwen-Image 2.1、Breeze TTS 2 只能非商用，見 `THIRD_PARTY_NOTICES.md`）；本 repo 只告訴你去哪裡下載，不重新散布 |
| 每台電腦不同 | venv 綁 CPU 架構與 Python 版本（桌機 x64、RTX Spark 是 ARM64），不能跨機共用；放進同步資料夾反而會被另一台蓋掉 |
| 已有可重現的取得方式 | `setup/downloads_*.json` 記了來源、鎖定版本（commit）與逐檔雜湊，換電腦照清單重下就是一模一樣的檔案，不需要靠 repo 搬 |

`.gitignore` 已排除 `*.safetensors`、`*.ckpt`、`*.gguf`；新增其他權重格式時一併加進去。

## 5.（選用）Breeze TTS 2（C:\AI\BreezeTTS）

> 2026-10-14 起預設配音引擎是 VoxCPM2（語音環境 `C:\AI\Voice`，聲音設計＋台詞都用它）。本節與 5b 只有要用選用引擎 `VOICE_ENGINE=breezyvoice`（台灣腔較準、可標注音）時才裝。

照官方 repo 裝在獨立 venv；`tools\breeze_batch.py` 頂端寫了程式庫與權重路徑。**權重非商用**。只用來設計新角色的參考音。

> **平台：官方只支援 Linux。** breeze-tts README 的需求寫明「Linux and Python 3.10 or newer」＋CUDA 顯卡，官方測試環境是 Docker 映像（要編 flash-attn）。
> 這裡是**非官方的 Windows 做法**（上游作者跑通過、有實測數據，本專案尚未在自己的機器上驗證）：`breeze_batch.py` 只走官方 `infer.py` 的 eager 路徑（`attn_implementation="eager"`），不用 flash-attn、不走 CUDA Graph 加速；套件照 `setup\env\requirements_breeze_venv.txt` 鎖定（Python 3.12＋cu128 torch）。出問題時官方不會支援。
>
> 它在本工作流只用一次（每個新角色設計一段參考音），跑不起來時有三個替代：
> 1. **送 Colab 跑**（Linux，正是官方支援的環境）：`cloud/colab_h3.py full-setup`，見 `cloud/README.md`。
> 2. **改用 VoxCPM2 聲音設計**做參考音（語音環境 `C:\AI\Voice` 已裝；這就是 2026-10-14 起的預設做法）。
> 3. **用真人錄音**當參考音（要有該聲音的使用權）。

## 5b.（選用）BreezyVoice（C:\AI\BreezyVoice）

選用的台詞配音引擎，Apache-2.0。裝法見 `AGENT_SETUP.md` 2d（Python 3.10＋uv、`--no-deps` 照 `setup\env\requirements_breezyvoice_venv.txt`、Windows 用 `setup\breezyvoice\winstub` 取代 pynini）。原專案版本：程式 commit d592c9d、模型 `MediaTek-Research/BreezyVoice-300M` rev e33b502、torch 2.7.1+cu128、onnxruntime-gpu 1.23.2、transformers 4.45.2、g2pw 0.1.1（`num_workers=0`，否則 Windows 卡死）。

> **平台：官方沒寫「只支援 Linux」，但安裝說明與相依套件都以 Linux 為準**（2026-10-11 查 mtkresearch/BreezyVoice 原始 repo）：
> - README 的安裝步驟是 Linux 指令（`sudo apt-get install cudnn9-cuda-11`、`export PYTHONUTF8=1`），另附 Docker 部署；要求 Python 3.10。
> - `requirements.txt` 把 `onnxruntime-gpu` 與 `deepspeed` 限定 `sys_platform == 'linux'`，在 Windows 照官方清單裝會被跳過。
> - 文字正規化套件 `WeTextProcessing` 依賴 `pynini`，**PyPI 上的 pynini 只有 Linux x86_64 wheel**，Windows 用 pip 裝不起來。
> - 官方 GitHub issue 查不到 Windows 相關的回報或支援說明。
>
> 本專案的 Windows 做法（`AGENT_SETUP.md` 2d，上游作者跑通過、有實測數據；本專案尚未在自己的機器上驗證）：照 `setup\env\requirements_breezyvoice_venv.txt` 用 `--no-deps` 裝（含 Windows 版 `onnxruntime-gpu`），用 `setup\breezyvoice\winstub` 取代 WeTextProcessing（代價：不會自動把數字轉國字，`breezyvoice_batch.py` 只轉阿拉伯整數，其他寫成國字）。出問題時官方不會支援；跑不起來就送 Colab（Linux）。
> **RTX Spark 筆電（Windows on Arm）**：Python 3.10 的 numpy、scipy、pandas 等沒有 ARM64 wheel，預設送 Colab，見 `docs/hardware_rtxspark.md`。

## 6. OpenAI 生圖（預設：API 金鑰優先、Codex CLI 次之）

`gen_image.py` 預設 `IMAGE_BACKEND=auto`，每張圖開始前依序選：

1. **OpenAI Image 2.5 API**（金鑰）：找得到金鑰 → 用它，會印 `[backend] img25`。模型確定是 Image 2.5（`gpt-image-2.5-sunburst`），所以排第一。
2. **Codex CLI**（ChatGPT 訂閱）：沒有金鑰、但這台找得到 `codex.exe`、已用 ChatGPT 登入、`image_generation` 開著 → 用它，會印 `[backend] codex`。
3. 兩者都不行 → **停下報錯**。

已經選定後端、生成時才失敗（API 錯誤、訂閱額度、逾時）也是**停下**，不會改試另一個，也不會改用本機 Qwen（畫風不同、角色參考圖也不同）。要固定用某一個：`IMAGE_BACKEND=img25`、`codex` 或 `local`（單張用 `--backend`）。`--lora`、`--uncensored`、Krea 一律在本機跑。

**Image 2.5 API**（`tools/img25.py`）：金鑰找法（先找到先用）：環境變數 `OPENAI_API_KEY` → `OPENAI_KEY_FILE` 指向的檔案 → `~/.openai.env`（全域技能 `agent-draw` 用的同一個檔）。金鑰檔可以只放金鑰，也可以寫一行 `OPENAI_API_KEY=sk-...`。
```
setx OPENAI_API_KEY "sk-..."
```
`img25.py` 不會印出金鑰。每張約 20 秒，走 API 計費。
可調：`IMG25_QUALITY`（預設 medium）、`IMG25_REF_SCALE`（預設 0.707，參考圖縮成一半面積；角色不像時設 1 比對）、`IMAGE_FALLBACK=1`（API 失敗時退回本機，預設不退）。

**Codex CLI**（`tools/codex_image.py`）：交給本機 Codex 的內建生圖代為生圖，扣的是 ChatGPT 訂閱額度（訂閱與 API 是兩套帳），每張約 1 分半。**Codex 內建生圖用的模型版本從外部無法確認**（紀錄裡沒有寫），不一定是 Image 2.5；有金鑰時想用它要明確設 `IMAGE_BACKEND=codex`。
- 找 `codex.exe` 的順序同 `agent-draw` 路線 C：`CODEX_EXE` → Windows Codex App → `~/.codex/.sandbox-bin/codex.exe` → PATH。要 `codex login status` 顯示 `Logged in using ChatGPT`、`codex features list` 的 `image_generation` 為 `true`。
- 參考圖用 `codex exec -i` 附上（轉面圖、表情表、場景裁切都會送），結果置中裁成要求的比例再縮成要求的尺寸；Codex 不吃 seed，不滿意只能刪檔重生。
- 片尾名單會寫「OpenAI 生圖（Codex）」。

## 6b.（選用）Blender（預演用）

只有要做 Blender 預演（布置圖、運鏡）才需要。從 blender.org 下載**安裝版**、用預設路徑安裝（`C:\Program Files\Blender Foundation\Blender 5.x\`），版本 **5.1 以上**（Blender Lab 官方 MCP 的要求）。不放在 `C:\AI\` 底下，也不用設環境變數。

操作方式交給全域技能 `agent-blender`：算布置圖用它的背景 runner（會自動在 `Program Files` 找到 Blender），要讓 agent 即時操作 Blender 畫面再照它的說明裝官方 MCP。細節見 `skills/ai-film/references/previs/blender-rules.md`〈前置〉。
